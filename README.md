# Sweet Surprises — Редактор на ценоразписи

React приложение (Vite + Tailwind + shadcn/ui) за ценоразписи върху фонова снимка. Направено е да се ползва лесно от телефон.

## Какво може

- Избираш готов ценоразпис
- Добавяш заглавие, подзаглавия и услуги с минути и евро
- Гледаш резултата върху снимката
- **Свали снимката** — на телефон се отваря менюто за споделяне, там избери „Запази изображение“ / Снимки
- **Цял екран** — скрива бутоните, за да направиш скрийншот

Промените се пазят в браузъра. „Върни оригиналния ценоразпис“ зарежда файла от папката отново.

## Стартиране

**Най-лесно:** двойно кликване на `start.bat`.

Или от терминал:

```bash
npm install
npm run dev
```

Отвори http://localhost:8080

От телефон в същата Wi‑Fi мрежа използвай Network адреса, който Vite показва (напр. `http://192.168.x.x:8080`).

## Структура

```
public/
  images/шаблон.jpg     ← фон по подразбиране
  fonts/                ← шрифт по подразбиране
  price-lists/          ← ценоразписи и config.json
src/                    ← React приложението
```
